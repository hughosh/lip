# Retained scenario evidence

These tests use the existing deterministic seam exchange and actual harness collaborators. Private fills are explicit inputs; public trades are never converted into hypothetical fills. The integration receipt runs the cumulative source tree. Different tests expose the applicable effects of each fault, rather than duplicating every collaborator assertion in every case.

| Scenario | Final-consumer evidence | Selected controls |
|---|---|---|

New authority before placement; quiet agreement, mismatch cancellation, capped exit resize and independent REST refresh. | M-F2-NEWEST-RECONCILE, M-F5-STALE-WS, M-F5-ALLOW-ADDING, M-F5-OLD-TRUTH |
