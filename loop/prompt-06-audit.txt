## ONE DIRECTIVE CLAUSE THAT WAS MISSED AND THEN FIXED

Your §9 says: "There must be no production in-memory fallback, and a nil lookup
must fail closed without refreshing fills truth."

The first implementation failed closed inside `risk.Portfolio.ApplyFills` -- SEV1
`OWNERSHIP_LEDGER_UNAVAILABLE`, global stop, no fill applied -- but
`wsx.ApplyPortfolio` still set `Applied[TruthFills]` and still called
`NoteTruth(TruthFills, ...)`, so the freshness clock advanced on a read nothing
could interpret. Under A13 that keeps authorising placement.

It is fixed: `ApplyPortfolio` now has an explicit `own == nil` branch that
discards the fills result, emits SEV1, requests a global stop and does NOT touch
the clock. The sub-test is
`TestFillConversionFailureDiscardsTheWholeWalk/nil_ownership_ledger`. This
change was made after the mutation catalogue was first run, so the catalogue was
re-run afterwards; the figure above is from the re-run.

## CHOICES THE IMPLEMENTER MADE THAT YOUR DIRECTIVE DID NOT SPECIFY

Listed for adjudication, not defended. Each changes behaviour or the exported
surface.

1. **`ApplyFrame` and `ApplyDisconnect` are METHODS on `*Gate`**, not free
   functions. `ApplyPortfolio` is a free function, because you gave it an
   explicit signature.

2. **Additional exported `Gate` methods** you did not name: `NoteSeqGap`,
   `NoteTruth`, `NoteDisconnectSustained`, `Tick`, `TruthAge`, `Reducing`,
   `Generation`, `Connected`, `Tickers`, `CancelPermitted`.

3. **F4's threshold is detected in ONE place, the supervisor.** Your §3 has the
   supervisor emit the disconnect-reduce event; your §4 has the gate keep the
   market REDUCING after recovery. Implementing the threshold in both would put
   two clocks on one rule, so `Gate.Tick` carries only F5 (quiet), and the gate
   learns about F4 through `NoteDisconnectSustained(down, now)`. Consequence:
   the gate cannot reduce on a sustained disconnect unless the caller relays the
   event, and `lip-3af` must wire that. Filed as `lip-0qj` (P1) so the relay
   cannot be forgotten: if `cmd/harness` wires the supervisor without calling
   `Gate.NoteDisconnectSustained`, F4 is silently dead and the socket can be
   down for an hour with no market reducing.

4. **`CancelPermitted(ticker, now) bool` returns a literal `true`.** It exists so
   "cancels are never gated" is a thing a test can assert and a mutation can
   break. The repository has previously found a guard that was dead defensive
   code and SURVIVED its mutation, so a constant function is exactly the shape
   that has bitten this project before. Confirm or replace it.

5. **`ORDER_SIDE_CONFLICT`, SEV1 + global stop, a class you did not specify.**
   An order acknowledged on one side and filled on the other cannot be resolved
   arithmetically -- the max()-of-cumulatives reconciliation needs one sign per
   order, and applying either reading moves q the wrong way by twice the fill.
   The event is dropped and a stop is requested. `risk/position.go:order`.

6. **`FRAME_UNDECODABLE`, SEV2, and the frame is NOT delivered to
   `core.Rig.Handle`.** A frame that does not decode as an envelope might be a
   book frame, so it cannot be certified book-safe. This is stricter than
   `core`, which would decode it itself and return an error.

7. **`WS_ERROR_FRAME`, SEV2**, for an `error`-typed frame; it IS still delivered.

8. **`risk.Portfolio.Positions()`**, an extra accessor returning a copy of every
   non-flat market. Not in your §5 list.

9. **The pong deadline is a `Timer` on the injected `Clock`, not a
   `context.WithTimeout`.** A `context.WithTimeout` reads the real clock, so F1's
   ladder would be undrivable by the scenario exchange and untestable at any
   speed a gate can run at. The ping itself still runs on a cancellable child
   context.

10. **`PortfolioRead` carries ONE completion `Stamp` for the cycle.** Your §6
    says "maintain independent last-success clocks for positions, orders and
    fills"; that independence is expressed by WHICH endpoints get `NoteTruth`
    called, in `Gate.truthAt[3]`, not by three separate read timestamps.

11. **`ApplyPortfolio`'s `time.Duration` parameter is read as the monotonic
     reading at APPLICATION time**, distinct from `read.At` (when the cycle
     finished). Freshness is stamped from `read.At`; the `TRUTH_STALE` anomaly is
     evaluated from `now`. Your signature gave the parameter no name.

12. **Poller coalescing** is implemented by rearming the timer with
    `interval - elapsed`, floored at zero, so an overrunning cycle owes exactly
    one immediate tick.

13. **`fee_cost` conversion**: `rest.ParsePrice4` then `×100` into `num.Money`
    (1e-4 dollars to 1e-6 dollars). An empty or unparseable `fee_cost` invalidates
    the whole fills result.

14. **Backoff ladder** is a fixed array 1, 2, 4, 8, 16, 32, 60 seconds with 60 as
    the terminal rung.

15. **A malformed `Command` is ignored rather than failing the session.** The
    caller's defect does not justify dropping a healthy socket.

16. **`Gate.OnConnect` and `Gate.ApplyDisconnect` BOTH advance the generation**,
    so it moves by two per cycle. Invalidation is by generation mismatch and
    nothing is erased.

17. **Test-only**: the fake clock exposes `BlockUntilStops(n)`, counting `Stop()`
    calls, because it is the only signal a test has that the session has FINISHED
    resolving a ping rather than merely been woken. Without it the ping tests are
    races.
